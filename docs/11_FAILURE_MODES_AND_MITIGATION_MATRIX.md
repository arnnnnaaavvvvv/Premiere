# 11. Failure Modes & Mitigation Matrix

Every autonomous distributed pipeline will encounter edge cases. Premiere implements automated graceful degradation across all subsystems:

| Failure Mode | Root Cause | Immediate Diagnostic Signal | Automated Mitigation & Fallback Strategy | User-Facing Experience |
| :--- | :--- | :--- | :--- | :--- |
| **Site Automation Blocked** | Cloudflare Turnstile, Akamai Bot Shield, or CAPTCHA challenge. | HTTP 403/503 response; Playwright navigation timeout; DOM contains challenge iframe. | 1. Stealth re-try with randomized viewport and user-agent.<br>2. Fallback to OpenGraph hero image & Google Web Cache snapshot.<br>3. Remotion substitutes live screencast with simulated 3D Ken-Burns parallax pan over static snapshot. | Pipeline completes with high-res static mockup; banner informs user of bot protection fallback. |
| **Empty or Sparse Repo** | New repo, minimal commits, missing `README.md` or `package.json`. | GitHub API returns empty file list or < 100 bytes README content. | LLM shifts weighting from repo code to live site DOM: crawls `<meta name="description">`, `og:title`, `<h1>`, and hero subheadings. Synthesizes brief purely from live website text. | Video successfully generates using live site copy without error. |
| **SPA Hydration Delay** | Heavy client-side JavaScript bundle (e.g. Next.js, Vite) rendering white screen. | `document.body.innerHTML` has < 5 child elements; network idle timeout triggered. | Worker waits for `document.fonts.ready` plus a fixed 3,000ms hydration grace window. Injects polling loop checking for non-empty `#root` or `main` selector before recording. | Smooth 60fps capture with fully hydrated UI components. |
| **LLM Schema Invalidation** | LLM outputs truncated JSON or invalid fields not conforming to Pydantic schema. | Pydantic `ValidationError` raised during JSON parsing. | Automated repair loop: returns error traceback and bad JSON back to LLM with instruction to fix syntax (max 2 retries). If still failing, applies deterministic template fallback. | Seamless user experience; zero pipeline crash. |
| **Playwright OOM Crash** | WebGL memory leak or massive DOM size exceeding container limits. | Docker container exits with code 137 (SIGKILL / OOM). | Worker supervisor catches SIGKILL, flags task for isolated worker with 4GB RAM quota, disables WebGL hardware acceleration, and restarts capture. | Brief 15s retry delay; progress status reflects automatic recovery. |
| **Audio Beat Misalignment** | Atypical time signature (e.g. 3/4 or 7/8) or ambient track with weak percussion. | Librosa returns confidence score < 0.4 on downbeat tracking. | Pipeline falls back to static mathematical grid based on nominal track BPM (e.g., exactly 2.000s cuts for 120 BPM). | Video remains strictly rhythmic without awkward fractional cuts. |
| **SSE Connection Drop** | Client network fluctuation or mobile backgrounding. | Browser `EventSource` triggers `onerror` event. | Next.js frontend implements exponential backoff reconnect with `Last-Event-ID`. API replays missed state transitions from Redis buffer. Polling fallback triggers if SSE fails 3x. | Seamless auto-reconnect without lost pipeline status or page reload. |
| **Malicious SSRF Attempt** | User submits `http://169.254.169.254/latest/meta-data` or private IP. | Pre-flight DNS resolution matches `BLOCKED_NETWORKS` CIDR table. | API instantly aborts pipeline, logs security telemetry, and returns RFC 7807 `400 Bad Request` with `ERR_SSRF_PROHIBITED`. Task is never enqueued to Redis. | Explicit descriptive error banner explaining why private IPs are disallowed. |
| **Remotion Render Timeout** | Complex CSS animation or missing S3 asset stalls Chromium rendering. | Remotion process does not emit frame progress for > 60 seconds. | Watchdog timer aborts stalled worker, downloads cached scene frames, re-renders solely the missing scene chunk, and stitches with FFmpeg. | Pipeline finishes within the 3-minute SLA window. |
